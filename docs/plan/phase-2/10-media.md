# Phase 2 · Chunk 10: Media: lead art, video, audio, and a preflight script

**Goal:** Media that is fast, captioned and safe by default, plus a Node script that blocks a merge when media
breaks the rules.

**Reference:** diatour-nyt §VI.V (safe video default: no autoplay with sound, captions, `preload="none"`,
poster), §VI.VII.4 (media preflight with ffprobe), §VI.VII.5 (sensitive-imagery checklist), §VIII.II
(`picture`, `srcset`, `sizes`, width/height), §I.VI ("Listen" audio).

## Learn first
- [web.dev Learn Images](https://web.dev/learn/images), [`vite-imagetools`](https://github.com/JonasKruckenberg/imagetools) (generates AVIF/WebP sizes at build)
- [MDN: `<track>` and WebVTT](https://developer.mozilla.org/en-US/docs/Web/API/WebVTT_API)
- [ffprobe docs](https://ffmpeg.org/ffprobe.html)

## Tasks
- [ ] **Lead art:** a React `<ResponsiveImage>` component (`<picture>` with AVIF + WebP generated by vite-imagetools), `sizes="(min-width: 760px) 720px, 100vw"`, explicit width and height, `fetchpriority="high"` on the lead image only. Use an image you made or one with a public-domain or CC0 license, with credit in `.credit`.
- [ ] **Inline images:** `loading="lazy"`, `decoding="async"`. Alt text written for the argument, not "image of."
- [ ] **Video block** (`{.video}`): `controls playsinline preload="none" poster`, plus a captions `<track default>`. Muted loops are allowed only with `muted loop autoplay` **and** no audio stream (the preflight checks this) **and** a pause button (WCAG 2.2.2).
- [ ] **Listen player:** a native `<audio controls preload="none">` styled to match, with a link to the transcript and the duration as text.
- [ ] **`scripts/preflight.mjs`:** for each file in `public/media/`:
  - [ ] Over budget? Images over 400 KB, videos over 4 MB.
  - [ ] Video has audio? Then flag it "tap to play only."
  - [ ] Missing `-poster.avif` or `.vtt` sidecar?
  - [ ] Exit code 1 on failures. Add it as `npm run preflight` and as a CI step (`ffmpeg` is available in `ubuntu-latest`, or install it).
- [ ] `docs/sensitive-media-checklist.md`: autoplay rules, content notes, cropping, caption guidance for meaningful sounds.

## Done when
- The LCP element is the lead image, and LCP is under 2.5s on "Slow 4G" in DevTools.
- CLS is 0.00 (all media has reserved dimensions).
- `npm run preflight` fails on a deliberately bad file and passes on the real ones.
